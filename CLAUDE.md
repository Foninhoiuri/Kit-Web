# Kit Web

Instruções de uso e de manutenção: [SKILL.md](SKILL.md). Código em `kitweb.py`, dados em `catalogo.json`.

## Regras

- Nunca commitar `.env`, chaves, tokens ou senhas. Este projeto não precisa de nenhum segredo.
- Só biblioteca padrão do Python; nada de dependência nova.
- Depois de mexer no catálogo ou no código: `python kitweb.py teste`.
- Não inventar licença ou preço: se não conferiu no site, deixe `conferir`.
- Sensível neste projeto: nada. O catálogo é público (links e notas de licença).
